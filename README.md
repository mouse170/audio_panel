# 應援音控面板 (Audio Panel) `v0.2.0.0`

專為 Android 行動裝置設計之極簡滿版大按鈕音控介面（PWA 行動網頁應用）。內建 Google Drive（`1306` 資料夾）完整 15 首音檔（5 首主控曲目 x 3 版本）與 5 份應援歌詞，支援手機本地音檔匯入、雲端網址下載與 `IndexedDB` 永久離線快取。

---

## 一、 核心功能架構

1. **極簡滿版大按鈕（100dvh 免捲動）**：
   * **短按（Short Tap）**：即點即播；若點擊正在播放中的按鈕則立即停止歸零。不配置累贅的底部進度控制列，播放進度直接以按鈕內嵌背景色塊與剩餘秒數呈現。
   * **長按（Long Press 450ms）**：觸發震動回饋並彈出原生 `<dialog>` 單曲選單，可切換該曲目的子版本、檢視/編輯應援歌詞，或單獨替換該版本的本地/網路音檔。
2. **全域版本一鍵切換 ＋ 單曲個別微調**：
   * 頂部常駐 3 組全域版本切換鍵（`全體切主版 / A`、`全體切 A / B 版`、`全體切 B / C 版`），可一鍵將全場 5 顆按鈕同步切換至對應曲風版本。
   * 長按任一曲目按鈕可獨立覆寫該曲目的版本。
3. **動態按鈕配置與多組情境設定檔（Profiles）**：
   * 內建 3 組預設情境：`全場標準配置（5 首）`、`競賽項目專場（3 首）`、`決賽雙欄面板（高張力）`。
   * 支援動態新增/刪除曲目按鈕、調整按鈕排序、切換「單欄大橫條 / 雙欄大卡片」網格、隱藏特定曲目，並支援匯出/匯入 JSON 配置。
4. **本地與雲端雙軌 `IndexedDB` 離線快取**：
   * 支援一鍵將全部 15 首音檔寫入手機瀏覽器 `IndexedDB` 資料庫，離線或飛航模式皆可零延遲秒播。
   * 支援從 Android 手機單檔或批次選取 `.mpeg` / `.mp3` 本地檔案（自動修正 Android `video/mpeg` MIME 型態為 `audio/mpeg` 並依檔名自動配對槽位）。

## 三、 啟動與建置指令

1. **啟動開發與區網伺服器**：
   * 雙擊執行 `start_server.bat`，或執行：
     ```powershell
     npm.cmd run dev -- --host 0.0.0.0 --port 5173
     ```
2. **建置生產環境 PWA 發行包**：
   ```powershell
   npm.cmd run build
   ```
